# Falcon autopilot boundaries

An explicitly requested autopilot runs the same stoppable local monitor.
Defaults: 30-second polling, local worktrees, no remote workers, no auto-merge,
no issue closure and no PR creation. Steering may use observations to decide
the next action within the user's current authorization. Review failures, scope
overlap, unresolved amendments or incomplete reports prevent integration.

Do not install persistent scheduling or change approval/hook trust settings.
A stopped or interrupted monitor makes no further progress until restarted.
